# Podklady

Sem nahrávejte dokumentaci organizátorů, PDF, prezentace, obrázky, tipy a pravidla.
Bez povinného názvosloví a ručního indexu.

Agenti podle `AGENTS.md` procházejí seznam souborů a čtou relevantní podklady.
Pokud nástroj formát neumí přečíst, přiložte textový výňatek nebo výtah se stranou/slidem.

Sdílejte jen materiály povolené pro týmový Git a daný AI nástroj.
Pacientská data a přístupové klíče sem nepatří.
